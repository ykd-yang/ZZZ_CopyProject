# Zenless Zone Zero Fan Project (Blueprint-Only)

## 📖 프로젝트 소개

이 프로젝트는 **C++ 코드 없이 오직 언리얼 엔진의 블루프린트만으로** 만들어진 [젠레스 존 제로](https://zzz.hoyoverse.com/ko-kr/)의 팬메이드 모작 프로젝트입니다.

## ✨ 주요 기능

커밋 로그를 바탕으로 구현된 주요 기능 목록입니다.

### 캐릭터 및 전투 시스템
- **플레이어 캐릭터 (Anbi)**
  - 기본 이동 (걷기, 달리기) 및 3인칭 카메라
  - 다채로운 콤보 공격 시스템
  - 회피(Dodge) 기능 및 관련 무적 판정
  - 스킬 및 필살기 구현
  - 대미지 및 HP 시스템

### 적(Enemy) 및 보스(Boss)
- **기본 적 AI**
  - 플레이어 감지 및 추적
  - 다양한 공격 패턴 (근접, 원거리)
  - 적 스폰 및 관리 시스템
- **보스 몬스터**
  - 복잡한 공격 패턴 및 페이즈 변화
  - 보스 전용 UI 및 연출 (대사 등)

### UI 및 연출
- **인게임 UI**
  - 대미지 수치 표시
  - 대화 시스템 (Dialogue)
  - HP 바, 스킬 아이콘 등
- **시각 효과 (VFX) 및 음향 효과 (SFX)**
  - 공격, 피격, 스킬 사용 시의 시각 효과
  - 캐릭터 및 환경 음향 효과

### 레벨 및 환경
- **다양한 테스트 맵**
  - 기능 구현을 위한 여러 테스트 레벨
  - 내비메시(NavMesh)를 활용한 AI 이동 영역 설정

## 🚀 시작하기

이 프로젝트는 C++ 코드를 포함하고 있지 않으므로, Unreal Engine 에디터에서 `.uproject` 파일을 열기만 하면 바로 확인하고 실행할 수 있습니다.

1. 이 프로젝트를 클론하거나 다운로드합니다.
2. Unreal Engine (권장 버전: 5.x)을 실행합니다.
3. `ZZZCopyProject.uproject` 파일을 열어 프로젝트를 로드합니다.
4. 에디터 내에서 원하는 맵을 열고 'Play' 버튼을 눌러 테스트합니다.
